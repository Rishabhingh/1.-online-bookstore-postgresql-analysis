# Online Bookstore SQL Project - PostgreSQL
A hands-on SQL project built using **PostgreSQL & pgAdmin 4** to analyze an online bookstore database. This project covers everything from basic `SELECT` statements to advanced business analytics.

# What I Did
- Created relational tables with Primary & Foreign Keys
- Wrote **11 Basic Queries**: Filtering by genre, country, date, price, stock, revenue calculation.
- Wrote **9 Advanced Queries**: 
    - Total books sold per genre/author
    - Average price, most frequently ordered book
    - Top 3 expensive Fantasy books
    - Customers who spent > $30, highest spending customer
    - Remaining stock after orders using `LEFT JOIN` & `COALESCE`

# Tech Stack
`PostgreSQL` `pgAdmin 4` `SQL` `Joins` `Aggregate Functions` `Group By`

# Key Learnings
Joins, Subqueries, Data Aggregation, Business Logic Implementation in SQL
